                          ReactJS và React Native
     A. ReactJS
- Mục đích: Xây nhà trên đất liền (Website chạy trên trình duyệt Chrome, Cốc Cốc, Safari...).

- Vật liệu xây dựng: Gạch, Xi măng, Sơn (HTML, CSS, DOM).

- Bạn viết code: <div>Hello</div>

- Trình duyệt hiểu: "À, vẽ một cái khối chữ nhật chứa chữ Hello".

- Kết quả: Một trang web (.html, .js) ai có link cũng vào được.

    B. React Native
- Mục đích: Xây nhà trên đảo hoặc dưới biển (App Mobile chạy trên điện thoại iPhone, Android).

- Vật liệu xây dựng: Gỗ chuyên dụng, Kính chịu lực (Native Components).

- Trình duyệt (Chrome) không hiểu vật liệu này. Chỉ có điện thoại mới hiểu.

- Bạn không được dùng thẻ <div> hay <h1>. Bạn phải dùng thẻ <View>, <Text> của riêng nó.

- Kết quả: Một cái App (.apk cho Android, .ipa cho iOS) phải tải từ App Store/CH Play về.


                            React = ReactJS.
- .js: Dùng cho file chỉ có logic (Hàm, Biến, Config).

- .jsx: Dùng cho file Component (Có chứa giao diện HTML/JSX).
